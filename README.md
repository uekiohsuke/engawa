# 縁側（Engawa）

能動的に会話ができるデスクトップ上の隣人。仕様は [neighbor-spec.md](neighbor-spec.md)。

## 構成

- **コア**（`engawa/core`）：FastAPI の常駐サーバー。会話履歴DB（SQLite）、LLM 呼び出しを持つ。
  UI へは WebSocket（`/ws`）でイベントを配信する。
- **UI**（`engawa/ui`）：PySide6。Discord 風のチャット本体と、キャラクター一覧から開く対話ウィンドウ。
- **LLM**：Ollama の OpenAI 互換 API。`ENGAWA_LLM_BACKEND=mock` で LLM なしでも動作確認できる。

## セットアップ

```powershell
python -m venv .venv          # Python 3.11
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
Copy-Item .env.example .env   # 必要に応じて編集
```

## 起動

```powershell
.\run.ps1                     # コア＋UI をまとめて起動
# 個別に起動する場合
.\.venv\Scripts\python.exe -m engawa.core
.\.venv\Scripts\python.exe -m engawa.ui
```

- チャンネル `# main`：メッセージのメインスレッド
- サブチャンネル：話題ごとのスレッド。キャラクターが即興の話題で話しかけるときに立つほか、「＋ 新しい話題」で自分でも立てられる。
  サブチャンネルでは長期記憶だけを参照する。3日間発言がないと自動でアーカイブされる（右クリックで名前変更・アーカイブ）
- キャラクター一覧で名前をダブルクリック：対話ウィンドウ（最前面）。立ち絵がデスクトップに直接立ち、横に吹き出しが出る。
  ドラッグで移動（位置は次回も使う）、Ctrl+ホイールで大きさを変えられる
- 立ち絵・アイコンは `engawa/assets/` に置き、`engawa/characters.py` の `CharacterImages` に相対パスで登録する
  （立ち絵は表情名ごと。未登録の表情は `normal` で代用）
- 表情：返事の先頭に付けさせた感情タグ（`[joy]` など）で対話ウィンドウの立ち絵が変わり、言い終えて30秒で `normal` に戻る。
  表情の説明は `EXPRESSION_DESCRIPTIONS`（`engawa/characters.py`）
- 「状態を見る」：状態確認ビュー（暇度・疲労・眠気、応答可能状態、性格タグ、生活リズム、
  プロンプトに注入される状態、状態イベントの履歴）。キャラクター名の横にも 🟢起きている／🟡取り込み中／🌙睡眠中 を表示

- 「集中モード」：ONの間は対話で話しかけず、`# main` へのメッセージだけで送ってくる

内部状態は `ENGAWA_STATE_TICK_SECONDS`（既定60秒）ごとに実時刻で更新され、コア停止中に経過した時間も起動時に反映される。

## 能動発話

`ENGAWA_JUDGE_INTERVAL_SECONDS`（既定60秒）ごとに、確率的ゲート → 判定層（`ENGAWA_JUDGE_MODEL`）→ 生成層の順で
話しかけるかを決める。起きていれば対話ウィンドウが自動で開き、`ENGAWA_DIALOGUE_TIMEOUT_SECONDS`（既定180秒）
返事がなければ同じ内容が `# main` に送り直される。判定の理由は状態確認ビューのイベント欄に残る。
状態確認ビューの「今すぐ判定」で、ゲートを無視して判定層を呼べる（調整用）。

## 読み上げ

対話ウィンドウでの発言を VOICEVOX で読み上げる（`#main` やサブチャンネルは読まない）。
`.env` の `ENGAWA_VOICEVOX_PATH` にエンジンの `run.exe` を指定すると、UI が起動・終了を行う。
話者は `ENGAWA_VOICEVOX_SPEAKER`（既定 47）。対話ウィンドウの 🔊/🔇 で ON/OFF を切り替えられる。

## 記憶

記憶v2（プロフィール型。仕様8章）。

- **短期記憶**：会話ログのうち、まだエピソード化していない発言。エピソード化が済んでも画面の履歴は消えない
- **エピソード記憶**：短期記憶から切り出した出来事単位の記憶。返事のたびに埋め込み（`ENGAWA_EMBED_MODEL`、既定 bge-m3）で
  意味検索し、関連する上位3件をプロンプトに入れる（類似度：対話・メイン 0.55、サブ 0.65）。
  削除猶予（3〜21日、詳しく書かれたものほど長い）と時限（30日）を持ち、思い出されると両方延びる。
  500件を超えたら、猶予の切れたものから少しずつ消える
- **プロフィール（印象層）**：マスターと自分についての印象（各1000字以内）。常にプロンプトに入り、睡眠中にだけ書き直される
- **記憶調整**：判定層が選んだときに、短期記憶をエピソード化し、印象メモと「思い出し」の会話の種を作る。
  続いている最新の会話はエピソード化しない
- **睡眠中の整理**：眠りに落ちたら、残りの短期記憶をすべてエピソード化し、印象メモから印象層を書き直して「話題作成」の種を作る
- **会話の種**：能動発話のときに1つ選ばれる（種があっても20%は即興）。期限3日
- **画面の様子**：前面ウィンドウのタイトルとアプリ名だけを30秒ごとに記録し（期限1日）、即興で話しかけるときに材料として渡す。
  本体の「画面を見る」で ON/OFF。集中モード中・除外アプリ（`ENGAWA_ACTIVITY_EXCLUDE`）・縁側自身のウィンドウは記録しない

状態確認ビューの「記憶」タブで中身を確認でき、「記憶調整を実行」「睡眠中の整理を実行」で手動実行もできる（調整用）。
v1（STM・LTM）の記憶データは、起動時に削除される。
